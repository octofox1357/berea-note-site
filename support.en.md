# BereaNote Support

## Which Bible file can I import?

BereaNote does not include any Bible text. You import a Bible file that you already have.

BereaNote reads Bible EPUB files and tries several layouts automatically. It has been checked with:

- the **EPUB edition of the New World Translation of the Holy Scriptures**, which its publisher offers free of charge at jw.org (Korean, English, Spanish, Portuguese, Italian, French, German and Japanese editions), and
- public-domain English Bibles in EPUB form from ebible.org (for example the World English Bible, the Berean Standard Bible and the American Standard Version).

Other Bible EPUB files are read when their layout can be recognized. Book names are matched in the eight languages above, so a Bible in another language may not be recognized. If a file cannot be read, the import screen says what was found and offers **Copy diagnostic info**, which you can include when you write to us. The copied text lists only file names inside the EPUB and counts; it contains no personal data and no Bible text.

Only one Bible can be installed at a time.

### Getting the file

1. Open jw.org in your browser and go to the Bible's page.
2. In the download options, choose the EPUB format.
3. Save the file. On iPhone and iPad it is saved to the Files app.

### Importing it

- **Mac**: open the Bible section and click **Import Bible**, or drag the `.epub` file onto the Bible pane. You can also use **Settings → Bible → Import EPUB…**.
- **iPad and iPhone**: open the Bible section, tap **Import Bible**, and choose the file in Files.

The import takes a few seconds. The app reads the file once and builds an index on your device; the original file is not changed.

### "This file can't be imported"

The file is not a Bible EPUB whose layout the app can recognize, or the download was incomplete. The message under the button says how many documents were read and how many verses were found. Download the EPUB again and retry. If a Bible you expect to work still fails, tap **Copy diagnostic info** and write to the address below with the text and the name of the edition.

### "Imported in part"

The app read the file but found fewer than the Bible's 1,189 chapters, so some chapters will be empty. The file is usually a partial edition or an incomplete download. Download the complete EPUB again and choose **Import Again**. A new file that reads fewer chapters than the Bible already installed is not used; to switch to it anyway, delete the current Bible in Settings first.

## Trying the app without a Bible

**Settings → Data → Samples → Fill** adds sample notes, folders and a sample timeline line. The sample content is in Korean in this version. **Settings → Danger Zone → Samples → Delete…** removes the samples again.

## Moving your data to another device

**Settings → Data → Backup → Create Full Backup…** writes a ZIP file with your notes, timelines and recordings. On the other device, restore it with **Settings → Danger Zone → Restore from Backup → Restore…**. Restoring merges the backup with what is already there and first keeps a safety copy of the current data.

## iCloud sync

Turn it on in **Settings → iCloud Sync** on each device, signed in to the same Apple Account. Notes, folders and timelines sync. Recordings do not: the list of recordings and their time marks sync, but the audio stays on the device that recorded it. To move audio, use a backup.

If the same note was changed on two devices before they could sync, the app keeps both: the later one stays in place and the other is saved next to it as a conflict copy.

## Recordings

Tap the microphone button in a note to record. Text you type while recording gets a time mark; tap the mark to play from that moment. Trimming a recording only hides the trimmed part from playback; the original audio is kept.

## Page lock

A password hides locked pages inside the app. It does not encrypt files, and there is no password reset, so keep the password somewhere safe.
